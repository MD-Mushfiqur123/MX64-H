# MX64 Master Plan Index

Primary task breakdown: `docs/architecture/MX64_MASTER_WBS.md`

Current project rule: **no simulation until the complete planned RTL and integration source review are finished.**

Current high-level order:
1. Requirements and architecture decisions
2. ISA and privileged architecture freeze
3. Core-wide interface contracts
4. Frontend and decode
5. PRF, rename, free list and checkpoint recovery
6. Dispatch, ROB, issue and execution units
7. LSU and memory ordering
8. L1/L2 caches and external memory fabric
9. MMU, TLB, page-table walker and protection
10. CSR, traps, interrupts, debug and platform
11. Full-core integration and source review
12. Final simulation/formal campaign
13. Synthesis, FPGA, ASIC physical design

This plan is a work breakdown, not evidence that all tasks have been implemented.
